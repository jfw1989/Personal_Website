# Personal Website – Jan-Frederic Wuttke

Willkommen im Repository meiner persönlichen Website!  
Diese Seite dient als digitale Visitenkarte und kombiniert meine beruflichen Erfahrungen im Fitness- und Technologiebereich mit meiner Leidenschaft für moderne IT-Lösungen.

## Inhalt

Die Website enthält:
- Eine kurze Vorstellung meiner Person und meines Werdegangs
- Ein Portfolio ausgewählter Projekte (Smart Home, Server- und Netzwerkinfrastruktur, Webentwicklung)
- Einen strukturierten Lebenslauf
- Kontaktmöglichkeiten

## Tech-Stack

- **HTML5 & CSS3** – Handgeschriebener, semantischer Code
- **JavaScript** – Für einfache Interaktivität
- **Responsive Design** – Optimiert für Desktop & Mobile
- **GitHub Pages** – Deployment direkt aus diesem Repository
